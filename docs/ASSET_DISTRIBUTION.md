# Reconstruction Assets

This source checkout does not contain model checkpoints or task recordings. Obtain checkpoints from the official upstream model providers using [LOCAL_INFERENCE.md](LOCAL_INFERENCE.md).

The original full project's historical artifacts were archived at [HY-LiYihan/Agentic-RSR-experiment-results-20261007](https://huggingface.co/datasets/HY-LiYihan/Agentic-RSR-experiment-results-20261007). The recorded dataset is private and requires an authorized account; access has not been verified by this extraction. It also contains downstream experiments outside this checkout's scope.

For Real-to-Sim, the relevant artifacts are source videos, Stage 1 inference and registration/delivery, Stage 2 accepted Blend scenes and evaluation evidence, and Stage 3 XML/assets/physics reports. Preserve source hashes, full asset bundles and referenced files when reusing a delivery. Historical absolute paths may need relocation; see [DATA_CONTRACT.md](DATA_CONTRACT.md).

Robot assets and derived point clouds retain their upstream terms; repository or dataset access does not change those terms. See [THIRD_PARTY.md](THIRD_PARTY.md). Historical publication media may remain in `docs/assets/` and `data/runs/`; these files are not runtime inputs to Real-to-Sim.
